Sales API

A simple Sales API project built with Flask and Python.

Features

- Sales by city
- Top customers
- Sales statistics
- REST API endpoints
- Flask backend

Project Files

- "main.py" - Application entry point
- "api.py" - Flask API routes
- "database.py" - Database operations
- "sales_app.py" - Sales analysis logic

Run the Project

python main.py

The server will start on:

http://127.0.0.1:5000
